Agent Framework · Open-web Video Search · Multimodal Verification

RACLO

Real-world Abductive Cognitive Logic Retrieval. RACLO is a Recall–Search–Verify agent that turns fragmented video memories into abductive web queries, processes candidate videos, and verifies the result at both video and frame granularity.

Shared paper RVMS-Bench Recall–Search–Verify ReAct web agent
Publication context

Third author with equal contribution; Tao Yu served as project leader. RACLO is the agent framework in the same paper as RVMS-Bench, not a separate standalone paper.

Agent objective

Reason from effects back to a searchable cause

A remembered scene is an effect of a larger, unknown source video. Directly searching the memory text often returns generic visual matches. RACLO instead asks what source, topic, event, or narrative could plausibly have produced the global impression, key moment, temporal context, and auditory memory.

\[ \begin{aligned} (G,K,T,A) &\longrightarrow \text{Abductive}\\ &\longrightarrow \text{Query Expansion}\\ &\longrightarrow \text{Web Search}\\ &\longrightarrow \{\text{candidates}\}\\ &\longrightarrow \begin{bmatrix} \mathrm{Verify}_G\\ \mathrm{Localize}_{KTA} \end{bmatrix}. \end{aligned} \]
Global impression \(G\) is most useful for source-video verification; key, temporal, and auditory memories \(K,T,A\) provide fine-grained localization evidence.
Stage 1 · Recall and Search

Expand uncertain memories into multiple web-search hypotheses

The agent uses abductive reasoning to form video-level queries, interacts with web search tools in a ReAct loop, and collects candidate URLs. A rule-based fast path can recognize direct or repeated URLs; otherwise content verification prevents a metadata-only match from accepting a reupload or unrelated copy.

Stage 2

Candidate preprocessing

  • Download candidate videos that survive URL and metadata checks.
  • Extract audio separately so auditory clues are not lost.
  • Use fixed-count frames for video matching and duration-adaptive frames for localization.
Stage 3

Parallel verification

  • Video-level matching tests the global impression against sampled visual and audio evidence.
  • Frame-level localization grounds key, temporal, and auditory details.
  • Model-based checks reject plausible-looking but unsupported candidates.
Why two granularities

Finding the source and finding the moment are different decisions

Video-level evidence

Topic, style, narrative, full audio, and global appearance identify the source.

Frame-level evidence

Anchor details and local temporal context identify the remembered moment.

Independent rejection

A candidate can match globally yet fail localization, so both checks must pass.

Scope and limits

An open-world agent whose environment can change

RACLO is evaluated with RVMS-Bench, but its web-facing behavior also depends on search ranking, page availability, download success, and tool latency. The explicit Recall–Search–Verify decomposition makes those failure points visible rather than collapsing them into a single opaque retrieval score.
