Omni-Embedding

A full-modality representation learning project for aligning text, image, video, audio, ASR/OCR, and video summaries into a shared embedding space for retrieval, reranking, recommendation, and content understanding.

Text / Image / Video / Audio Qwen2.5-Omni Backbone Bidirectional InfoNCE Hard Negatives Hierarchical Batch Sampler Deduplicated InfoNCE

Problem

Industrial multimodal systems rarely receive clean single-modality input. A video item may contain frames, speech, OCR, title, comments, topic metadata, and user-intent signals. Omni-Embedding focuses on turning these heterogeneous signals into a shared representation space that supports cross-modal retrieval and downstream recommendation.

The project is positioned as an omni-modal pre-training task rather than a narrow retrieval feature. It explores one backbone for text, image, video, and audio, then adapts the learned space to recall, reranking, generative retrieval, and cold-start recommendation.

Data Construction

  • Video to summary + ASR + OCR semantic descriptions.
  • Text-video, video-video, video-audio, and item-to-item pairs.
  • Near-duplicate, same-event, same-topic, and segment-level video pairs.
  • Hard negatives mined by embedding models and refined with stronger MLLMs.
  • Recommendation-style chains such as item-to-item and query-plus-item-to-item tasks.

Training Recipe

  • Multi-stage pre-training from general multimodal data to high-quality task data.
  • Hierarchical batch sampling by modality combination, task, domain, and subcategory.
  • Deduplicated contrastive loss to reduce false negatives inside a batch.
  • Task-homogeneous batches so different modality/task types are not mixed in one batch.
  • Model soups / merging for robust checkpoint selection without extra inference cost.

Architecture

The implementation notes use an omni-capable MLLM backbone, with the Qwen2.5-Omni Thinker path as the embedding base. Instead of stitching separate modality towers after the fact, modality features are substituted into the language stream and the final hidden state is projected into a shared embedding space.

  • Base model: Qwen2.5-Omni-style multimodal backbone.
  • Embedding head: final-layer last-token representation, optionally adapted by PCA for compact serving dimensions.
  • Optimization: freeze selected encoders when useful, then tune attention/MLP paths with lightweight adapters.
  • Efficiency: dimension choices such as 1024-d, 256-d, and 64-d trade retrieval quality for index and serving cost.

Key Objective

The core training objective is a contrastive alignment loss. The practical trick is not only the loss itself, but controlling false negatives and batch composition so that semantically close samples are not incorrectly pushed apart.

L = -log exp(sim(q, k+) / tau) / sum_j exp(sim(q, k_j) / tau) Bidirectional InfoNCE: optimize query -> key and key -> query retrieval. Deduplicated InfoNCE: remove negatives whose source or target modality similarity exceeds a threshold. Distributed negatives: all-gather embeddings across GPUs to enlarge the negative pool.

Task Matrix

  • Text query to video, image, audio, or text document.
  • Video to video via front/back segments, same event, or similar-topic pairs.
  • Video to audio and audio to audio for cross-signal alignment.
  • Item-to-item and query-plus-item retrieval for recommendation-oriented matching.

Hard Negatives

  • Same event with slight visual drift: similar enough to be confusing, not identical.
  • Same subject but different event, verified by embedding filters and MLLM/LLM checks.
  • Tag-overlap near misses for fine-grained semantic discrimination.
  • Segment-order negatives where adjacent clips should rank above distant or random clips.

Why It Matters

This line connects pre-training, retrieval, reranking, and recommendation. It also reflects a systems view: the quality of an embedding model depends on model backbone, multimodal data construction, negative mining, batch sampling, and serving constraints together.

Public-safe impact can be summarized directionally: better cold-start semantic recall, complementary recall coverage against legacy semantic channels, and a manageable dimension/quality trade-off for production ANN indexes.
