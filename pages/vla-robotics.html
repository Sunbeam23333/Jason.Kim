Robo-Dopamine 2.0

OOD-Aware Temporal Memory for Process Reward Modeling. This research prototype extends state-only reward assessment with compact, time-ordered visual history so a scorer can distinguish genuine task progress from superficially plausible but task-breaking transitions.

Relationship to prior work

This page documents my ongoing 2.0 extension. The original Robo-Dopamine work by Tan et al. is the technical foundation; it is cited here as related work rather than presented as a publication I co-authored.

Research question

Can the same visual transition mean different things under different histories?

A static scorer sees only the current before/after evidence. In long-horizon manipulation, that can be ambiguous: an object may look closer to a goal while an earlier prerequisite was skipped, or an OOD perturbation may preserve local appearance while breaking the task trajectory. Robo-Dopamine 2.0 adds bounded history without changing the underlying VLM or process-reward backbone.

State space

Train on normal progress, robust perturbations, and task-breaking negatives

Normal positives

Successful transitions that advance the intended manipulation trajectory.

Robust OOD cases

Perturbed observations whose before/after evidence remains valid but whose context should be reconstructed from the corresponding successful source trajectory.

Task-breaking negatives

Transitions that may look locally reasonable but invalidate future task completion.

For OOD examples only, the prototype keeps the perturbed before/after observations intact and rebuilds the preceding history from the matched successful trajectory. This isolates the perturbation while preserving a coherent account of prior progress.

Baseline input

Static eight-view panel

The baseline combines start/end references with high, left, and right views before and after a candidate transition.

\[ I_{\mathrm{static}} =[r_s,r_e,b^{\mathrm{high}},b^{\mathrm{left}},b^{\mathrm{right}}, a^{\mathrm{high}},a^{\mathrm{left}},a^{\mathrm{right}}]. \]
Memory input

Bounded temporal panel

The memory variant inserts a small set of pre-transition and intermediate panels, then retains three synchronized views around the scored transition.

\[ I_{\mathrm{mem}} =[r_s,r_e,P_{\mathrm{pre}}^{1:K}, b^{1:3},P_{\mathrm{mid}}^{1:L},a^{1:3}], \qquad K\leq3,\ L\leq1. \]
Model compatibility

Keep the scorer architecture fixed; change the evidence it receives

Both static and memory panels are serialized into the same multimodal scoring interface. The experiment therefore tests the value of temporal evidence without requiring a new process-reward backbone.

\[ \begin{aligned} s_\theta&=f_\theta(x,I),\\ \mathcal L &=-y\log\sigma(s_\theta)\\ &\quad -(1-y)\log\!\left(1-\sigma(s_\theta)\right). \end{aligned} \]
\(x\) is the task instruction, \(I\) is either the static or memory panel, and \(y\) marks whether the transition reflects valid progress.

Status

Evaluation plan, not a published performance claim

Robo-Dopamine 2.0 is ongoing work. The method page records the hypothesis, input construction, and ablation design; it intentionally does not report final numbers before the evaluation is complete and publicly documented.

  • Measure classification quality separately on in-distribution and OOD transitions.
  • Check whether history helps task-breaking cases rather than merely easy positives.
  • Audit sensitivity to history length, panel ordering, and source-trajectory matching.
