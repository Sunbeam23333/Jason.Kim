Research Program · Open-domain Retrieval · Agentic Search

Open-world Video Search

A three-project research line for recovering videos from incomplete memories. ShotFinder begins with a described shot; RVMS-Bench formalizes richer long-video memories; RACLO turns those memories into an auditable Recall–Search–Verify agent.

Research arc

From one remembered shot to structured multimodal memory

Shot-level description Open-web source retrieval G / K / T / A memory model Dual-granularity verification

The projects share an open-world motivation but answer different questions. They are presented separately below so each benchmark, method, publication, and authorship record remains precise.

Project 01 · Shot retrieval

ShotFinder

Imagines likely source-video context, expands it into web queries, retrieves candidate videos, and grounds the remembered shot.

  • 1,210 verified samples across 20 topics.
  • Second author, equal contribution.
Open project page
Project 02 · Benchmark

RVMS-Bench

Defines real-world long-video search and moment localization from global, key, temporal, and auditory memories.

  • 1,440 verified samples across 20 categories.
  • Third author, equal contribution.
Open benchmark page
Project 03 · Agent framework

RACLO

Uses abductive query expansion, tool-using web search, and parallel video/frame verification to recover the source and target moment.

  • Method in the RVMS-Bench shared paper.
  • Third author, equal contribution.
Open method page
Common principle

Retrieval is a reasoning-and-verification process

Reason

Infer missing source context from incomplete human memories.

Search

Interact with the changing open web instead of assuming a frozen candidate pool.

Verify

Ground the final answer in video-, frame-, temporal-, and audio-level evidence.
