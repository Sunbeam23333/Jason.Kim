StreamDiT

Memory-centric inference for minute-scale video generation via layer streaming from host memory and context-parallel denoising.

PDF Layer Streaming Context Parallelism Commodity Multi-GPU

Problem

Minute-scale video generation pushes activation memory, KV/cache memory, model weights, and context length beyond what a single GPU can comfortably serve. StreamDiT treats memory as the core bottleneck and designs inference around it.

Approach

  • Stream model layers from host memory to reduce peak GPU residency.
  • Use context-parallel denoising to distribute long temporal contexts.
  • Preserve generation quality while targeting practical commodity nodes.

Portfolio Value

  • Connects model architecture with serving memory planning.
  • Complements WorldDistill's training/inference abstraction.
  • Highlights train-infer infra experience for video generation systems.
