Omni IIE Bench / VDE Bench

Evaluation-oriented work for instruction-guided image editing and visual detail editing, with attention to practical model capability rather than only isolated visual quality.

CVPR 2026 Instruction Following Regional Fidelity Global Quality

Evaluation Gap

Image editing systems need to preserve the original content while applying targeted changes. A good benchmark should therefore evaluate global image quality, local edit fidelity, and instruction compliance together.

Dimensions

  • Whether the requested region or attribute is actually changed.
  • Whether unrelated areas remain stable.
  • Whether the final image is visually plausible and semantically consistent.

Why It Connects

  • Benchmarks guide post-training and model selection.
  • Fine-grained evaluation helps compare foundation editing models.
  • It complements retrieval and multimodal pre-training work with evaluation design.
